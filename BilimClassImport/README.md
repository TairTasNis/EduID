# BilimClass Importer

Утилита выгружает сводные оценки из личного кабинета BilimClass в JSON.

1. Запустите `start.cmd`.
2. Введите логин и пароль BilimClass. Символы пароля скрыты при вводе.
3. Выберите по номеру учебный год, класс и четверть. Enter подтверждает вариант в квадратных скобках. Списки загружаются из вашего аккаунта.
4. Откройте файл в папке `exports` по пути, который покажет утилита.

Для запуска нужен Node.js 20 или новее. На других платформах выполните npm start в папке утилиты.

## Что в JSON

`academicYear`, `class` и `quarter` содержат выбранный период, а `subjects` — строки из сводной таблицы.

- `marks` содержит все оценки из строки. Поле `kind` обозначает тип: `formative` (ФО), `sor` (СОР), `soch` (СОЧ) или `other` (например, отметка о посещении). Исходная пометка сайта, например `БЖБ`, хранится в `type`. Для работы `7/10` сохраняются `value: 7`, `max: 10` и `percent: 70`.
- `formativePercent`, `sorPercent` и `sochPercent` содержат вклады из сводки BilimClass. `totalPercent` складывает доступные вклады. В незакрытой четверти это текущий процент по выставленным оценкам. Если в сводке нет числовых вкладов, `totalPercent` равен `null`.
- `predictedGrade` и `finalGrade` содержат прогноз и выставленную оценку. Пустые ячейки и прочерки превращаются в `null`, текстовые статусы сохраняются как строки.

Утилита подключается к API BilimClass по HTTPS. JSON сохраняется локально.
