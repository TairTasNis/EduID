# СУШ НИШ Актобе

Утилита выгружает оценки и табели из школьного аккаунта в JSON. Нужен Node.js 22.19 или новее.

1. Выполните `npm ci` и `npm start` в этой папке.
2. Введите ИИН и школьный пароль. Ввод пароля скрыт.
3. Выберите все доступные годы или конкретный год, четверть либо табель.
4. Откройте JSON в папке `exports`.

Команда `npm start -- --quarter 2` выгружает указанную четверть текущего учебного года. Если школьный сайт требует CAPTCHA, утилита сообщит об этом. Проверьте вход на школьном сайте.
